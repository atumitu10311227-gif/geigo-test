# AI思考トレーニング — AI接続準備版 0.4.0

基準日：2026年9月9日。指示の基準：承認済み第12版。

## 現在地

AI接続を行うためのコードと、端末内の保存・再開・削除を組み込みました。
ただし、本物のOpenAI APIへの接続、Vercelへの配置、スマートフォン実機での保存・復元、フィードバックの内容精度はまだ確認していません。
本物のAIとの動作確認が済むまでは「完成した訓練アプリ」「効果実証済み」とは扱いません。
このZIPは接続・配置用の一式です。HTMLを開くだけで有料AIとの対話が始まるファイルではありません。

## 敦司様が今すぐ行う必要のないこと

コードの書き換え、APIキーの取得、クレジットカード登録は、まだ必要ありません。
最初にファイルを置くためのGitHub接続を確認します。既存の迎合テストを壊さないよう、新しい別リポジトリを使う方針です。
有料設定は、使用モデルと費用を確認し、本人の了承を得てから行います。
APIキー、パスワード、カード情報をチャットへ貼らないでください。

## 今回入れた機能

・仕事／対人関係／ダイエットの3コース。
・場面と選択肢を同じ画面で表示。
・選択後の固定解説、自由質問、その質問へのAIフィードバック。
・自然なAIとの対話。AIは第12版の方針をもとに、必要な意見・提案を行う。
・対話後の本人の判断と理由を保存し、全体を4節のフィードバックで返す。
・承認済みのフィードバック締めと共通クロージング。
・直近1回の入力・会話・結果をブラウザ内に保存。再開・削除・任意のテキスト書き出し。
・失敗時の入力保持。失敗を仮応答で隠さず、自動再送もしない。
・利用コードを知る人だけAIを利用できる簡易制限。アカウント管理は作っていない。

事後テスト、質問の書き直し、点数、企業管理画面、研究記録の自動集中収集は入れていません。

## 往復数

開始時のAI回答は、アプリが用意した場面に対する最初の回答です。
その後の「本人の送信＋AIの返答」で1往復です。3往復後から振り返り可能、最大6往復。
6往復後は最後の返答を読む時間を残し、ボタンで次へ進みます。勝手に画面を切り替えません。
中断は別扱いで、開始画面から再開できます。通信中の中断は外部側で処理済みの料金まで取り消すものではありません。

## 仕組み

画面 → 同じサイトの /api/ai → OpenAI Responses API（応答生成の接続口）

対話、短い自由質問へのフィードバック、最終フィードバックで指示を切り替えます。
使用モデルはサーバー設定で明示的に選びます。未設定ならAI通信は動きません。
安いモデルや別モデルに、自動で切り替える処理はありません。

サーバーは会話を研究用データベースへ保存しません。会話本文をログへ出す処理もありません。
各リクエストは `store:false`、画像生成・検索などの追加ツールは使用しません。
ただし、外部サービスの監視ログ・キャッシュ・通信記録までゼロになることは保証しません。
保存・削除は、このアプリがブラウザ内に保存したデータに対する操作です。外部側の記録や手動保存したファイルは別です。

最終フィードバックは、4つの本文と短い根拠引用を決めた形式で受信します。
引用が元の記録と一致しない場合は、誤った結果を表示せずエラーにします。
この検査で確認できるのは引用の一致であり、思考分析の正しさ全体ではありません。
利用者画面では専門的な分析タグや7要素の名称を表示しません。

## 後で設定する項目

設定はVercelのEnvironment Variables（サーバー側の設定欄）に置きます。

`OPENAI_API_KEY`：OpenAIの秘密の認証キー。公開コード・ブラウザ画面には入れない。
`OPENAI_MODEL`：料金と利用可否を確認して選んだモデル名。必須。
`OPENAI_REASONING_EFFORT`：必要な場合のみ。モデルが対応する設定を選ぶ。未確認なら空欄。
`PILOT_ACCESS_CODE`：利用者へ渡す別の利用コード。ランダムな16文字以上。APIキーとは別。
`PILOT_AI_ENABLED`：通常は false。課金条件に同意して動作確認する段階で true にする。

この版はVercelでFramework Preset（構成方式）を Other（その他）、出力先 public とする構成です。
公開先でのビルド・配置はまだ未実行です。非公開で保存することと、配置後の画面URLが非公開であることは別です。

## 費用に関する重要事項

ChatGPTの契約とAPI利用料は別です。
どのモデルを使うかで料金が変わるため、ここでは利用料金やモデルを勝手に確定していません。

このアプリには、文字数・応答長・往復数の制限、連続送信防止、簡易利用コード、サーバー処理ごとの一時的な回数制限があります。
ただし、サーバーが複数立ち上がる・再起動する場合、一時的な回数制限は共有されません。
これは「必ず何円で止まる」仕組みではありません。無制限の一般公開用ではなく、本人と少数の許可された利用者向けです。

OpenAIのプロジェクト予算は通知用の上限で、超過してもリクエストが継続する場合があります。
前払いでも停止処理の遅延によって超過が生じ得ます。自動補充は初期状態で有効の場合があるため、支払う前に確認します。
実接続は本人の費用了承を得てから、利用状況を見ながら少数回で行います。

Vercelの無料Hobby枠は、規約上、非商用の個人利用が対象です。条件を満たすかを配置時に確認し、企業向け運用や商用化にそのまま使えるとは想定しません。

## 開発者用の再現手順

Node.js 22を用意し、バックエンド確認は `npm test`。
ローカル起動は `npm run dev`。設定が無い状態ではAI通信は停止しています。
固定応答の画面試験では `node tests/fixture-server.mjs` を起動し、PythonとPlaywrightがある環境で `python tests/browser_check.py` を使います。
画面試験は保存器を代用するため、実機での保存確認は別工程です。
